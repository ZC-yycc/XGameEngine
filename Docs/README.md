## 活跃文档

活跃 = 随代码更新，**不是**“永远正确”。每份文档的第一屏必须写明体裁、回答什么、
不回答什么。

| 文件 | 体裁 | 唯一职责 | 什么时候必须改 |
|---|---|---|---|
| `README.md` | 用户指南 | 安装、运行、各功能怎么用 | 用户可见命令 / 行为变化 |
| `ROADMAP.md` | 状态台账 | 已完成 / 进行中的阶段与勾选 | 一个阶段落地或明确未完成项变化 |
| `FLOW.md` | 流程参考 | 启动 / 每帧 / 构建 / 数据流 | 主循环、调度顺序、构建流程变化 |
| `AGENTS.md` | Agent 入口 | 硬规则摘要 + 常用命令 + 约束索引 | 规范、命令、目录结构变化 |
| `Docs/差距分析.md` | 优先级真相源 | **当前开放差距**与排序 | 新差距出现 / 旧差距关闭 / 排序改变 |
| `Docs/决策记录.md` | 约束台账 | 不可推翻的约束、踩过的坑、实测数据 | 新增约束或旧约束被推翻 |
| `Docs/架构收敛约定.md` | 规范 / 政策 | 迁移 = 替换 + 拆除；违规判据 | 收敛政策变化 |
| `Docs/脚本API.md` | 参考手册 | Lua API 的叙述、示例、易错点 | 注册函数 / 参数 / 返回值变化 |
| `Docs/无头运行.md` | 使用指南 + 契约 | `--headless` 用法与 JSON 字段 | CLI 参数、JSON、退出码变化 |
| `Docs/MCP.md` | 接口参考 | MCP 工具、参数、返回 | 工具名、字段、错误语义变化 |
| `Docs/文档规范.md` | 规范 / 政策 | 文档分类、命名、归档、门禁 | 文档制度变化 |
| `Docs/文档整改计划.md` | 一次性计划 | 本次整改的现状、动作、剩余项 | 整改推进；完成后归档 |
| `Docs/README.md` | 索引 | 本页 | 增删 / 移动任何文档 |

## 冻结区

[`历史/`](历史/README.md) 只放**不再更新**的档案：一次性审计、已完成的设计稿、
历史实施记录、旧版本快照。那里的“未实现 / 下一步”都指写作当天，不代表今天。

归档不是删除：它回答“当时为什么”和“结论基于哪次提交”，这两件事当前代码答不了。
规则见 [`文档规范.md`](文档规范.md) §8。

## 三条维护规则

1. **一个事实只写一处**：状态进 `ROADMAP.md`，优先级进 `差距分析.md`，约束进
   `决策记录.md`；其他文档只链接，不复制。
2. **活跃文档不带日期文件名**：日期只属于历史档案与一次性审计。
3. **移动 / 归档必须当场改链接**：`tools/check-docs.ps1` 会检查根目录白名单、
   相对链接和归档横幅。
