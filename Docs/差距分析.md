## 当前开放差距（唯一现行排序）

排序原则：**先交付可靠性，再玩家可见的完整度，再规模化，最后长期能力。**
同一格里的条目没有先后；跨格依赖时先做被依赖的那格。优先级是编辑判断，
不是工作量估算。

### P0 — 交付可靠性收尾（不关闭就不宣称“可交付”）

| 差距 | 现状 / 边界 | 记录 |
|---|---|---|
| 多文件整体事务与机器掉电后的目录持久性 | 单文件原子写已统一走 `xgame_core::fsx`；发布有跨进程锁 + 可恢复事务标记，但“写到一半掉电”仍不保证目录项持久（Windows 无目录 fsync） | 决策记录 §四十九 / §九十；本文 R06 |
| 真·异常退出验证 | 正常退出 / 切关 / Stop 的钩子已覆盖；进程被强杀、panic、设备丢失下的资源回收仍未专项验收 | 本文 R11；历史 `PLAN.md` 第八十一节 |
| 发布包的真实 GPU 播放器路径 | hosted CI 只跑无头组合门禁；真实窗口、GPU、音频设备仍靠本地验收 | 本文 173 / 182；`README.md`「CI」 |

### P1 — 近期：把“能做完整游戏”的洞补上

| 差距 | 现状 / 边界 | 记录 |
|---|---|---|
| 嵌套 Prefab | 预制体实例已能引用资产，但资产内部不能再含预制体实例；结构性 Apply 不递归 | 2026-11-13 记录 |
| Prefab Variant | 只有整份 Revert 与结构性 Apply，没有“以另一预制体为基线”的变体 | 2026-11-13 记录 |
| 逐字段 override 可视化 | 实例本地值会保留，但 Inspector 不标“来自资产 / 已被覆盖”，也不能单字段 Revert | 2026-11-13 记录 |
| 多盏点光投影 | 阴影只认第一盏 `casts_shadow` 且 `range > 0` 的点光 | 决策记录 §八十 |
| 逐物体运动向量 | TAA 只有相机重投影 + 邻域钳制，快速横向移动仍有拖影 | 决策记录 §二十九 |
| 输入重绑定 UI | `InputMap` 支持多绑定 / 修饰键，但运行时没有改键界面 | 本文「玩法系统」输入行 |
| UI 输入框 | 只有文本显示 / 图片 / 按钮，没有可编辑文本控件 | 本文「玩法系统」UI 行 |
| 运行时多机位 / 正交相机 | 相机实体只有透视 + 单 active；编辑器视口有正交，运行时 split screen 未做 | 本文「玩法系统」相机行 |

### P2 — 规模化与产品化第二波

| 差距 | 现状 / 边界 | 记录 |
|---|---|---|
| ECS / 作业系统 | 线性 `Vec` 存储 + 单线程 update；1000 个互挤动态体 ≈ 13 ms/帧（rapier 求解器本身） | 历史 P2 #17 |
| 反射探针 / 局部环境 | 只有一张全局程序化天空 IBL；无反射探针、无局部环境 | 历史 P2 #19 |
| Shader 工具链 | 手写 WGSL 内联字符串；无 `.wgsl` 文件、无热重载、无变体、无可视化编辑 | 历史 P2 #21 |
| 2D（Sprite / Tilemap） | 缺失，渲染是纯 3D PBR | 历史 P2 #22 |
| 快捷键自定义 | 快捷键硬编码在 DCC 三处；无统一配置界面 | 历史 P2 #25 |
| 脚本调试器 | Lua `debug` 库刻意未加载，只有指令预算钩子 | 历史 P2 #30 |
| 音频流式 / 遮挡低通 | 固定三组总线与即时调音已做；长音频流式、遮挡低通 / 混响未做 | 历史 P2 #29 |
| GPU 粒子 / 贴图粒子 / 拖尾 | CPU 版已落地；万级以上、贴图序列帧、拖尾、粒子碰撞未做 | 历史 P1 #6 |
| 动画根旋转 / IK / 重定向 | 平移根运动已闭环；根旋转、IK、重定向与制作工具未做 | 历史 P1 #12 |
| 跨平台 | 仅 Windows 实测；wgpu / winit 理论可行，无 Linux / macOS / Web 验证 | 历史 P2 #31 |

### P3 — 长期

| 差距 | 现状 / 边界 |
|---|---|
| 网络 / 多人 | 缺失（无 tokio / socket / 序列化复制） |
| 地形 / 水体 | 缺失（无 heightmap / 水面） |
| 多窗口 | 缺失（egui 单窗口，面板不能拖出独立窗口） |
| 场景流式加载 | 缺失（单场景全量加载） |
| 光照烘焙 | 缺失（只有实时方向光 + 环境 IBL） |
| 输入录制 / 回放 | 缺失（输入层与窗口解耦，已为它留好口子） |

### 验证债（不算功能优先级）

| 项目 | 现状 |
|---|---|
| 真机手柄 / 触摸屏 | 代码路径有测试，但本机无设备，未做真机验收 |
| Miri / unsafe 证明 | 未运行 Miri；`ScriptCtx` 的调用窗口约定仍靠代码审查与回归 |
| Linux / macOS / Web | 未验证；见 P2「跨平台」 |
